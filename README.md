# Nihanth Sai — Cloud, DevOps & SRE Portfolio

A responsive portfolio built with React, TypeScript, Vite and custom CSS. It uses a premium, minimal visual style and is designed to run locally first.

## Requirements

- Node.js 20.19+ or 22.12+ (recommended current LTS)
- npm (included with Node.js)

Check your installation:

```bash
node -v
npm -v
```

## Run locally

1. Extract the ZIP file.
2. Open the extracted `nihanth-portfolio` folder in VS Code.
3. Open a terminal in that folder.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL printed in the terminal, usually `http://localhost:5173`.

Stop the server with `Ctrl + C`.

## Production build check

```bash
npm run build
npm run preview
```

Vite writes the production build to `dist/`.

## Before publishing

Search the project for and replace these placeholders:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

Also:
- Add a verified resume PDF under `public/` and link it from the page.
- Verify the exact title/date and credential URL for each certification.
- Review every experience bullet for accuracy and employer disclosure rules.
- Add public GitHub repository URLs and screenshots only after they are ready.
- Keep client names, internal network details, credentials, private dashboards and confidential screenshots out of the public site.

## Project content accuracy

The project cards distinguish hands-on projects, professional experience, work in progress and planned work. Update the status as each public repository and its documentation become available. Do not add invented performance metrics or claim a planned project is already complete.
